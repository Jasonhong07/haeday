## 결정 요약

**한국 사주를 아름답고 이해하기 쉬운 자기 이해 경험으로 제공한다.** 무료로 내 명식과 설명을 확인하고, $3.99로 명식 전체를 연결한 개인 풀이를 받는다. 얼굴·목소리 없이도 설명 자체가 유용한 짧은 영상을 만들어 영어권 고객을 유입시킨다.

1. 디자인: 달빛 네이비와 한지색을 유지한 편집물 스타일. 큰 문장 하나, 실제 결과 카드 하나, 무료 CTA 하나를 첫 화면에 둔다.
2. 유입: 영어 원본 주 5개 → Instagram Reels / YouTube Shorts / TikTok에 각각 맞춰 배포. Pinterest·검색은 같은 제작물을 재활용하는 보조 채널.
3. 차별화: ‘왜 이런 해석인가’ 근거 보기, 시간 모름의 정직한 설명, 유료 내용의 구체적인 맛보기, 구독 없는 결제와 쉬운 주문 복구.
4. 수익: 조회수 광고 수익이 아니라 Haeday의 환불 후 세전 상품 매출을 목표로 한다. 일본어·스페인어의 저렴한 제작/높은 수익을 전제하지 않는다.
5. 개발: 최초에는 독립 시안을 작성했고, 9/26에는 랜딩·입력 UX와 PayPal 오류 안내를 구현했다. 변경/검증 범위는 05 보고서 참조.

## 확인된 것과 가설

Dribbble 인기 피드의 노출과 좋아요/조회 수는 관찰했다. 이는 역대 순위, 사용자 구매 전환, 바이럴 성과의 증거가 아니다. 경쟁사 현재 매출 상위 순위는 검증 가능한 공개 자료를 확보하지 못했으므로 ‘매출 상위’라고 쓰지 않는다. App Store 평점 규모가 큰 비교 대상과 실제 공개 리뷰를 선정했다.

리뷰는 정성 표본이며 불만 빈도/전체 만족도를 추정할 대표 표본이 아니다. 일부 리뷰는 수년 전 작성되어 현재 제품에서 해결됐을 수 있다. 리뷰에서 느낀 정확성은 실제 예측 정확성의 증거가 아니다.

목표 기준은 D39: 환불 후 세전 상품 매출 $10,000/월. 환불·할인 없는 $3.99 주문 2,507건이 하한선이다. 환불률 5%, 전액 환불만 가정하면 약 2,639건 필요. 무료 쿠폰 주문은 매출/유료 전환에서 제외한다.

## 비용과 성공 판정

초기 추가 도구 예산은 **$0 목표**, 기존 개발·LLM 비용 제외. 무료 도구 제한을 만났을 때만 월 $20 이내 선택안을 별도 제안하며 자동 결제하지 않는다. 사용자 편집 시간도 비용으로 측정한다.

조회수만으로 성공 판단하지 않는다. `콘텐츠 → 프로필 → 사이트 → 무료 명식 → 결제 → 정상 열람`을 본다. 바이럴은 보장할 수 없다. 조회수는 크지만 사이트 방문이 없는 영상은 유료 획득 관점에서 실패일 수 있다.

설계 가설: 무료 체험 500회와 유료 주문 20건 정도가 모이기 전에는 세부 색상 A/B보다 유입·결제 장애와 문구 이해도를 우선 확인한다. 이 숫자는 통계적 유의성 보장이 아닌 초기 운영 기준이다.
